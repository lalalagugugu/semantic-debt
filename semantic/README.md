# semantic

语义内容的**源文件**。各档位的上下文由 `render/` 从这里渲染，不手写重复内容。

| 文件 | 档位 | 卡 |
|---|---|---|
| `conventions.md` | 企业约定清单（同义词、口径、默认过滤等），L1 起可见 | 种子已给，T07 定稿 |
| `source.yaml` | L1：业务名、全部关系、描述、枚举含义、同义词、文字指标口径；R 档由它去掉描述与关系渲染 | T08 |
| `widetables.sql` | L1.5W 明细宽表（只含行级派生列，不聚合） | T08 |
| `summary/` | L1.5S 汇总层（按主题、固定粒度的汇总表与维度表） | T08 |
| `metrics.yaml` | L2 指标清单（口径做成可调用对象） | T08 |
| `l0_map.yaml` | L0 劣化映射（晦涩命名、删描述、留约三分之一关系、暴露技术字段） | T09 |
| `tuning/` | L1 调优 / L2 调优的补充说明与示例，**只能来自调优包** | T14、T18 |

规则：本目录在 `semantic-v1` 冻结范围内。G1 之前题库侧（Codex）不得读取本目录下除 `conventions.md` 以外的文件。不得为了某几道题修改本目录（硬规则 3）。
