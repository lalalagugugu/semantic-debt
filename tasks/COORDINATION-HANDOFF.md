- 评估各会话的回报，起草裁决（`decisions/`），推分支、开 PR；**用户合并 PR，只有用户说「打 tag」才打 tag**。

- `git fetch` / `git push` / `gh pr` 单独成一条命令（复合命令会进沙箱失败）；`gh pr create` 用 `--body-file`。
- 付费调用：先 dry-run、用户批准预算、错峰。数据出站到任何模型 API 都要用户明确授权。

- 不写用户级全局配置或记忆（`~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`）。
