## 建议批准的规则

所有转换必须是确定性的通用规则，不使用题号、不调用模型、不执行候选 SQL、不按答案数值猜语义。对整份作答选同一套转换，保留重复次数；转换后仍调用原有数值、计数、身份、排名、排序和选择边界检查。不支持或有歧义时不新增判对。

| 编号 | 规则及必要条件 | 防止把真错判对的条件 / 反例 |
|---|---|---|
| P1 | **期间等价**：在明确识别为年、月、季度的维度上，允许整数与规范数字文本、无歧义期间标签、期间首日，以及完整年月/年季度的拆合。期间角色须有可审计的列信息或已有元数据支持；不能只凭数字落在 1–12 推断月份。 | 保留粒度和所有已表达的年份；跨年不得压成月份；完整日期仅在明确的月/季度维度且恰为首日时转换。非法日期、月中日期、跨年错位、缺年份造成的碰撞均拒绝；金额和计数不得走期间转换。月份参考没有年份时，只有可证明单一年份范围才可补足，否则保留原判。 |
| P2 | **长宽表等价**：允许一个分类维度的成员列展开或收拢，必须能从列信息确定每个成员和指标；按其余完整分组键建立一一映射。 | 不求和、不补零、不去重、不跨组搬值；缺成员、多成员、重复分组、指标对调、无法识别的列名均拒绝。不能只比较数值集合；含 Top-N/分组选择时，转换后仍须完整验证对象、名次和边界。 |
| P3 | **已保留身份的名称替代**：候选与参考均保留同一完整编码（含命名空间及复合键）时，允许参考的空名称或已明确标为占位的名称改用该编码展示。 | 编码精确匹配，正常名称仍须一致；不允许任意名称互换，不靠金额反推身份，不因名称唯一便丢掉必答编码。占位判据必须来自已有契约或经本次统一批准的定义，不能凭外观猜测、逐题列白名单。无法证明占位性质则不放宽。 |
| P4 | **冗余展示列**：允许忽略额外的标签、编码或常量列，前提是全部必答信息及原始行的重复次数仍完整匹配。先验证 v2 已有的列映射，只有确有缺口才新增实现。 | 不忽略额外行、不重新聚合；按额外维度拆组后行数增加仍错。额外列与已匹配对象身份或期间矛盾时拒绝，不能把错误身份当作“多余列”删除。不能因此放宽缺少必答指标、比率基数、编码或名次。 |

以上是建议范围，不意味着现有输入一定足以证明全部转换。实现时先核对执行结果中实际保留的列信息和题库已有 rules；缺失信息不能伪造，也不修改参考来凑输入。若需要新增评分元数据或映射来源，单列具体契约再请用户裁决。

## 建议保持原判的边界

- 不放宽数值容差、计数精确性、比例换算范围；已有规则不重复实现。
- 不删除参考的必答列。名称不能可靠替代编码，结果恰好没有重名不构成充分证明。
- 不忽略已有 ordered / order_by，不改变 Top-N 配额、并列边界和排名规则。Q94 一类“题面未指定但参考指定”的问题属于契约争议，不能由 v3 偷改。
- 不补比率分母、缺失名次或其他未返回的指标；不依据候选 SQL 或解释文字重算答案。
- 不把不同筛选、连接或聚合口径统一成同一种；本次只比较已返回结果的呈现。
