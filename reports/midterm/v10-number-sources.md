## 定义表（v10）

- 单元名：L0 低质量语义层；R 只给原始表结构（业务原名）；L1c 公开基准自带的文档；L1 内容完整的语义层；L1+ 完整且逐条消歧的语义层；复盘补语义；复盘补语义 + 作答要求；L1-onto 是 L1 全部换成本体写法；L3a-full 是 L1+ 全部换成本体写法；旧 L3a（只换 109 条）只在下篇附录主表。L1.5S、SQL-L2、JSON-L2 在下篇第 3 节定义，L1.5W 只在下篇附录。下篇第 5 节写基线、允许拒答、允许拒答 + 重罚答错。
- 本体：W3C 标准写法 OWL 2 / SHACL Core，内容逐条相同、只换写法，模型仍写 SQL。不包括 Palantir 式对象模型，也不包括模型写本体查询、引擎编译成 SQL 的做法；这两种进下篇「没有尝试回答的问题」。
- 数量：正文不写做法个数。单元数和作答次数只在下篇附录「规模」；5,439 另见下篇局限。
- 单位：差值写「个百分点」，需要判断谁减谁时用文字说方向；准确率写 %，一位小数。
- 范围：上篇第 1–3 节全部 98 题，第 4 节测试集；下篇第 1、2、3、5 节全部 98 题（第 3 节另有覆盖的题），第 4 节首轮报错用 98 题、准确率用测试集。
- 指纹：主表和上篇全部单元一个指纹（e72d3c7f）；下篇第 2 节和第 5 节的单元是另一个指纹（bc19ba97），都不和主表直接比，两节各自在同一批次里重跑了基线。版本变化的数字只在下篇第 5 节写一次，两个哈希只在下篇附录「本体对照」出现一次。
- 术语：口径只指指标的算法定义，判分方式写「评法」；L1+ 的提升写「消歧并补充常用概念」，不写成只靠消歧；ClickHouse、Cube、agent、系统提示、token 在上篇第一次出现时各有半句解释；统计显著、调优集、测试集在上篇实验描述定义，下篇「实验设置和上篇回顾」再简述一次；会查库的 agent 在下篇第 1 节定义；bootstrap 只在附录；错因三类写「怎么算」「是什么、属于谁」「SQL 问题」；自评写「自评答对概率」。
