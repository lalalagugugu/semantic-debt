# 中期报告名词表

| 名词 | 给非技术读者的解释 |
|---|---|
| 语义层 | 把技术表和字段解释成业务概念、关系与计算口径的说明或可调用对象。 |
| L0 | 信息不完整、命名晦涩的交付：没有业务说明，关系也不齐全。 |
| R | 只提供原始业务名的表结构，不提供描述和关系。 |
| L1 | 提供业务名称、关系、枚举含义、同义词、企业约定和文字指标口径。 |
| L1c | 外部基准原有语义文档，用作对照。 |
| L1.5W 明细宽表 | 在L1上预先连接常用表，仍保留明细行；不是事先算好的汇总结果。 |
| L1.5S 汇总层 | 只开放固定粒度的汇总表和维度表；某些明细问题因此无法回答。 |
| L2 | 将文字指标做成可调用对象，由实现固定计算方法。 |
| L1调优 | 在L1上使用允许查看的调优题包补充说明与例子；另有增加指令的单元。 |
| L1+ | 经过系统审查并由业务方裁定默认读法后的语义内容；默认读法参考了答案，应披露这种乐观条件。 |
| L3a | 与L1+相同内容的OWL与SHACL表达，用于比较表示形式。 |
| SQL / DAX / JSON | 三种查询表达方式：数据库查询、分析模型计算表达式、指标层结构化请求。 |
| 单元 | 查询栈、语义档位和作答方式的一个固定组合，如SQL-L1、JSON-L2。 |
| 直答 | 模型直接交查询；执行报错时将错误发回，固定允许修正一次。 |
| 探查agent（-E） | 模型可先调用只读查询工具查数据，再提交答案；本实验限制探查次数。 |
| C13教学阶梯 | 在L1内容固定时逐步增加查询写法说明的对照；第4级仅跑留出题。 |
| 一次作答 / rep | 同一道题的一次完整尝试，包含其探查和允许的修正；本报告正式运行一般每题三次。 |
| 最终正确率 | 最终被判正确的作答数除以纳入统计的作答数；执行失败与拒答仍计入分母。 |
| 首次即对 | 第一次提交就正确，无需报错后修正；与最终正确率不同。 |
| 三次全对 / 全错 / 时对时错 | 同题三次分别全部正确、全部不正确、或有对有错；全错也包括执行失败和拒答。 |
| 稳定性指标 | 时对时错的题占比；低表示判定一致，但可能一致地错。 |
| judge题 | 需要另定裁判流程的题；本期不放进准确率分母。 |
| 低区分度题 | 简单猜法也可能答对，或不同口径碰巧结果相同的题；从主表排除、在附表保留。 |
| 主表98题 / 附表109题 | 全部122题先去13道judge题，再从109题去11道低区分度题得到主表98题。 |
| 含/不含19题 | 对一组可能受指标文字与实现差别影响的题做敏感性比较；相关不代表已证实的错因。 |
| 配对差 | 在同一批题上逐题比较两单元正确比例，再求平均；用百分点表达。 |
| 95%自助法区间 | 有放回抽取题目多次，观察差值的波动范围；不是“真值有95%概率落在此处”的保证。 |
| 自评A / B / C | 肯定对、没把握、肯定不对三档；模型说肯定对也可能错。 |
| 根因类别 | 既有复核对“缺什么才能答对”的解释；文档缺失、文档歧义、模型没理解、题面歧义、参考或评分可疑。 |
| token | 模型处理文本的计量单位，不能直接等同于汉字；输出包含思考用量。 |
| 缓存命中 | 服务端复用了先前相同的消息前缀，因此部分输入按较低价格计费；以接口实报为准。 |
| rescore 离线重评 | 重新评判已保存的执行结果，不重新让模型作答；重评零费用不等于原运行免费。 |
| 孤儿行 | 事实行引用的维度键在维度表中不存在；内连接可能把这些行静默丢掉。 |
| 呈现差异 | 业务计算可能相同，但日期、标签、列组织等不同；本报告记录旧评分的边界，不自行翻分。 |
