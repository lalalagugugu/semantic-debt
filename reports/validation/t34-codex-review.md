### 「未做」理由逐项审查

判据是是否存在 OWL 2 / SHACL Core 的标准表达，而不是是否已有一个同名关键字。SHACL 的属性路径支持逆向、序列和 oneOrMorePath；属性的 value nodes 是路径可达值的**集合**，minCount 数集合元素，并非只能数行。依据：[SHACL 属性路径](https://www.w3.org/TR/shacl/#property-paths)、[SHACL 值节点](https://www.w3.org/TR/shacl/#value-nodes)、[SHACL minCount](https://www.w3.org/TR/shacl/#MinCountConstraintComponent)。以下没有引入 SHACL-SPARQL 或 SHACL-AF。
