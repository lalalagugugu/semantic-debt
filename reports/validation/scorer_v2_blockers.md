## 上一轮实现问题的处理

- 四项 5 万 / 20 万行错误答案超时：建边只展开最小的精确键桶或数值窗口，其他列随后核验；对单列 amount / count 的单调区间二分图，排序配对即最大匹配，不再展开稠密边。一般容差图仍使用容量最大匹配。
- 合列身份 KeyError：身份组件沿列对应见证合并，并保留 group / object 声明的顺序；候选不被猜拆为隐藏的字段。
- Top-N 参考域合法性：校验第 N 行之后全部属于同一量化边界；域小于 N 时比较全部实际行。
- 成对列含非必答编码：只投影两侧同时必答的位置；不要求候选提供非必答编码，也不允许人名拼接借用成对列。
- 原因码和输入：按 12.6 取最远失败、逐参考第一份原因；补齐未知字段、where 必答、数组编码、整数精确、空标签范围等校验。
