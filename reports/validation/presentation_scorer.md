# 通用展示评分规则验收（2026-10-18）

依据：decisions/2026-10-18-label-scoring-and-all-wrong-audit.md 第二、七节，以及 decisions/2026-10-18-names-required-by-system-prompt.md 第三节之二。全部实现仅依赖逐参考规则及数据，不按题号处理。

- 非数值字符串列中，参考为NULL或空白的标签可匹配候选字符串；候选字符串不得与该参考同列已有的其他非空标签冲突。数值NULL不因此变成0或字符串，其他标签照常比较。
- 候选原始相邻两列字符串按原顺序、空格拼接后可匹配参考字符串列。源列不复用，不拼接非相邻列，不交换名姓顺序。
- YYYY-MM-DD与同日零点日期时间等价；支持字符串和Python date/naive datetime。非零时刻、不明确时区、不同日期、非法日期不放宽。按期间分组的表示不靠评分器猜测年份或粒度。
- 计数0的组可有可无：至少有一个必答count列，必答count均为精确数值0，其他必答数值列均为0或NULL。参考和候选双向处理；不根据非必答列拒绝省略。计数为NULL、缺计数标注、非零必答金额、数值字符串不满足条件。保留Top-N数量及嵌套选择覆盖约束。
- 题库无序对象对的通用声明：`unordered_pairs: [{"left": [0,1], "right": [2,3]}]`。每侧列组等宽且不相交；键、名称等属性一起逐行交换，必答属性两侧须同时声明。其他列、重复次数和顺序约束照常比较。不声明时不放宽。

测试包含正例与反例：不冲突/冲突标签；数值NULL；拆列/拼错顺序/非相邻/源列复用；日期/零点/非零时间/时区/非法日期；零组双向省略/添加及计数0金额非零双向拒绝；无序对逐行反向及部分属性错配、缺行、数值错误。

验证：主仓库全套可运行测试351 passed、23 skipped，使用空数据目录跳过真实数据库集成。无数据库查询、模型调用和新依赖。600条与T12逐条重评尚未运行，由后续最终题库基线重评执行；不把合成测试当作这两项验收。

复现：设置SEMDEBT_EVAL_DIR，SEMDEBT_DATA_DIR指向空测试目录，使用已有项目环境运行 `uv run --offline --no-sync pytest --disable-warnings`。
